# 11 октября: Meets, панель разработчика, исправления с телефона

Что сделано (код, проверки типов, линтер, Knip, 195 тестов, web-скриншоты 390×844):

- **Название и иконка.** Приложение называется Meets (экран телефона, тексты, уведомления). Внутренние имена (`ryadom`, пакет, ключи хранилища) не менялись, чтобы не потерять сборки и данные. Схема ссылок: `meets://` и `ryadom://`. Иконка — человечек держится за две палочки (`scripts/icons.mjs`).
- **Заставка.** «Meets» пишется, точка падает в конец названия, карта раскрывается кругом из этой точки, потом плавно приближается к тебе. Системная заставка пустая, чтобы не было скачка.
- **Gemini не искал не из-за кода:** в журнале GitHub Actions ошибка 402 — на счёте Gemini API закончились деньги (AI Studio → Billing). Теперь панель пишет это прямо.
- **Панель разработчика.** Две вкладки: «Аналитика» (люди, события, метрики, вкус человека) и «Ивенты» (поиск Gemini, расписание, согласование, все события с поиском, источники). В каждой карточке всегда время, место, цена; чего нет — подсвечено.
- **Карта.** По умолчанию неделя (тумблер «Ближайшее время» — 24 часа). Камера больше не уходит в океан при первом запуске. Моя точка и конус направления рисуются слоями самой карты. Перелёт к событию не перестраивает все пины (из-за этого зависало).
- **Рекомендации.** Светлые карточки с фото события или постером раздела, внизу время / место / цена. Лента не зависает после «Мимо» (карточка возвращалась в колоду с занятым жестом).
- **Планы и чаты.** Смахивание влево открывает значки под строкой, как в Telegram, без окон. В диалогах видно последнее сообщение («Ты: …») и последнее действие («Вы оба идёте на …»); друзья без переписки показаны внизу.
- **Профиль.** Фото не загружалось: у бакета `avatars` не было права чтения, а загрузка шла с upsert. Исправлено (политика уже применена на сервере). Аватар на панели вкладок теперь не меньше соседних значков.
- **Навигация.** Два состояния: выбор (пешком / машина / автобус, «лучше», кнопки карты над панелью) и «в пути» (крупная инструкция, остаток, прибытие, скорость). Блоки не накладываются.
- **Адреса.** «Алма-Ата» → «Алматы». Поиск идёт сразу по Mapbox и OpenStreetMap, поэтому находятся дома, которых нет у Mapbox. Клавиатура не закрывает поля в шторках. Вылет после создания встречи: форма открывала вторую копию вкладок с лишней картой — теперь закрывается и возвращает к уже открытым.

Применено на рабочем Supabase: функция `admin_overview` (миграция 19), политика `avatars_read` (миграция 20).
Нужно от владельца: пополнить счёт Gemini API; собрать новый APK (Actions → Android APK).
Не проверено на телефоне: GPS и поворот конуса, жесты смахивания на Android, клавиатура, запись фото.
