# Проверка советов из трёх видео

9 ноября 2026. База сравнения — af32393, продолжение интерфейса после APK45. Советы относятся и к сайтам, и к серверу; приложение — Expo/React Native с Supabase. Ниже разделены изменения, уже существующие механизмы и недоступные для проверки части. Маркетинговые цифры из роликов не считаются замерами этого приложения.

| Совет | Проверка / действие |
|---|---|
| Сжимать фотографии, уменьшать размер | `src/chat/media.ts`: длинная сторона максимум 1080, JPEG 0.78 уже до загрузки. Не добавлены фиктивные параметры WebP к чужим URL. Внешние афиши требуют анализа источников после доступа к базе. |
| Отдавать WebP/AVIF | Нужна поддержка сервера изображений. Supabase image transformations нельзя включать вслепую: доступность и тариф не подтверждены. Пока используется штатный expo-image и подготовка пользовательских JPEG. |
| Загружать изображения по видимости | В рекомендациях ограниченная колода из 3 карточек. Список чатов переведён на FlatList: начальная порция 8, окно 5. Вне окна строки не должны держать аватары и анимации. |
| Не дублировать запросы | Выбранный друг карты использует общий `['person', id]` кэш с профилем/чатом. Снята загрузка полных профилей всех точек. Подписанные ссылки вложений кешируются, одновременные одинаковые пути объединяются. |
| Поиск после паузы | Поиск людей уже имеет debounce 300 мс, минимум 2 символа, максимум 10 результатов; результат старой строки не показывается для новой. Поиск чатов локальный и не создаёт сетевых запросов. |
| Пагинация API | Сообщения уже по 100 с курсором created_at + id; планы порциями по 30. События ограничены 500; полноценная серверная пагинация афиши требует сохранить семантику рекомендаций и дат карты, поэтому не заменена слепым limit(20). |
| CDN для статики | Mapbox/Supabase используют свои службы доставки, ресурсы Expo статические. Собственный домен/хостинг web не задан; отдельная CDN не разворачивалась. |
| Медленные операции в фон | Сбор событий выполняется worker/Actions. Переносить интерактивные действия пользователя в неподтверждённую очередь не требуется. Очередь отправки сообщений и оптимистичный интерфейс уже существуют. |
| Устранить N+1 | На карте полные сведения запрашивались для каждого друга (профиль, мои друзья, person_card, мои теги). Теперь только выбранный человек; остальные точки используют серверный результат приватности. Демо сохраняет локальную проверку canSee. Список чатов получает сводки одним RPC, а не запросом истории для каждой строки. |
| Brotli/Gzip | Нативный JS поставляется внутри APK; HTTP-сжатие для него не нужно. Для web включение — обязанность реального хостинга, которого в задаче нет. Локальный benchmark не выдаёт несжатые байты за production-трафик. |
| Redis для частых ответов | Для клиентского чтения уже TanStack Query; добавлено переиспользование signed URLs. Redis без плана запросов и серверной нагрузки не установлен, чтобы не нарушить актуальность сообщений/прав доступа. |
| Удалить неиспользуемые зависимости | `npm run knip` выполнен: неиспользуемых зависимостей не найдено. Есть только подсказка убрать старую ignore-запись @expo/config-plugins из knip.json; зависимости не удалялись ради формальной галочки. |
| Потоковая выдача ИИ | Пользовательского потока ответов ИИ в приложении нет; сборщик событий отдельный. Не добавлялась отсутствующая функция. |
| Оптимистичный UI | Сообщения/outbox, планы и настройки уже отображаются до ответа с обработкой ошибок. Сохранена существующая защита от двойной отправки и порядок go/undo. |
| Независимые запросы параллельно | Дополнительные адреса встреч и статистика участников событий теперь запрашиваются параллельно после списка событий. Раньше адреса задерживали начало статистики. |
| Индексы частых запросов | В миграциях есть messages(chat_id, created_at desc, id desc), memberships(user_id,chat_id), friendships(b,a), входящие заявки, индексы событий и географии. Применение и EXPLAIN в production заблокированы доступом к Supabase; новые случайные индексы не добавлялись. |
| Отслеживать медленные запросы | Сетевой probe повторён; CONNECT 403 до базы. Для реальной диагностики нужны применённые сетевые настройки/учётные данные. Ни время запроса, ни состояние индексов production не выдуманы. |
| Сервер рядом с базой | Регион текущего Supabase/worker требует проверки настроек сервиса. Клиент из телефона не переносится на сервер. |
| SSR для web | Expo web уже `output: static`, генерируются HTML-маршруты. Для APK SSR неприменим. |
| Сторонние скрипты после загрузки | В app/+html.tsx нет рекламных/аналитических внешних скриптов. Mapbox уже загружается отдельным динамическим модулем. |
| Делить JavaScript по страницам | В Expo Router включены production async routes только для web, Android/iOS сохраняют поддерживаемый режим. Web export и переходы проверяются после изменения. |
| Виртуализировать длинные списки | Основной список чатов теперь FlatList. Переписка уже виртуализирована с дозагрузкой; рекомендации ограничены 3 элементами. Дополнительные маленькие блоки заявок/друзей в шапке/подвале не заявлены как полностью виртуализированные. |
| Выбирать только нужные колонки | Для многих запросов уже явные поля: profiles для людей, memberships, attendance, locations. select(*) полных событий/профилей не заменён неподтверждёнными колонками без доступа к схеме; иначе старый сервер может перестать отвечать. |
| Пул подключений | Приложение использует HTTPS PostgREST/RPC; оно не открывает прямые PostgreSQL-соединения. Серверный pool Supabase настраивается сервисом, доступ к настройкам не получен. |
| Балансировка нагрузки | Отдельных самостоятельно развёрнутых серверов приложения в текущей конфигурации нет. Нет оснований создавать несколько серверов без нагрузки и замеров. |
| Кэш браузера / повторный визит | expo-image memory-disk и TanStack persisted cache уже используются. Новые signed URLs стабилизируют URL для повторного медиа. HTTP cache-control web зависит от хостинга. |
| Шрифты заранее и локально | Rubik/Pacifico из локальных пакетов включены в сборку, useFonts держит экран до готовности; внешнего Google Fonts запроса нет. Начертания используются в существующих экранах. |
| Слежение у реальных пользователей | Клиентский журнал сбоев и map telemetry уже есть. Данные client_errors сейчас недоступны; не объявлены проанализированными. |
| Проверять слабые телефоны | Web benchmark с CPU ×6 и нагрузочный сценарий 500 чатов / 10 000 сообщений; цифры не являются Android FPS. Физического Android/adb в текущей среде не использовали. |
| Избавиться от шаблонного дизайна | Прочитан Unslop, адаптация с авторством в `.skills/ryadom-interface/SKILL.md`; навигация/карточки изменены предыдущим коммитом. Эта итерация посвящена скорости. |
| Ограничить тяжёлые эффекты и фоновую работу | Экономный режим теперь отключает второй blur-слой и общей EventCover. Trail/traffic/weather polling карты отключён вне фокуса. Видеокэш ограничивается 64 МиБ до создания плееров (стандарт Expo — 1 ГБ). |
