| Jest | 329 тестов, 35 наборов |

| Ориентация сообщений в web | Исправлена перевёрнутая отрисовка; проверяется суммарное преобразование текстового узла |
| Браузер: вложения на 320×640 | Успех |

SQL выполнялся в изолированном PostgreSQL WASM с сокращённой схемой чатов. Это не проверка рабочего Supabase. Браузер использовал демо-данные, подменённый ответ маршрута и заблокированные внешние запросы. Нативные камера, сжатие, GPS, GPU, батарея и FPS на Poco/iPhone не измерялись.
