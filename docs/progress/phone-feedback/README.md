# Исправления по видео и 21 пункту обратной связи

Изменения готовы в коде. Web-сценарии и отдельная база PostgreSQL проверены. Сервер Supabase и установленное приложение этой работой не обновлялись: доступ к Management API не прошёл. Перед проверкой на телефоне нужно обновить сервер и собрать приложение по инструкции ниже.

| Пункты | Что изменено |
| --- | --- |
| 1–3 | Внутренние сборки скрывают логотип и атрибуцию Mapbox; карта всегда дневная. Своя точка — оранжевая анимированная с направлением, без синего системного значка и кольца точности. Кнопки карты перенесены к середине справа. Для релиза вернуть `EXPO_PUBLIC_MAP_ATTRIBUTION=true`. |
| 4, 9 | Неактивная карта размонтируется. Открытая карточка скрывает нижние вкладки только пока её экран в фокусе. Переход «Позвать → Чаты» освобождает панель; выбор вкладки и Android «Назад» относятся к текущему экрану. Кнопка выбранного события — «В планах». |
| 5 | Жест закрытия шторки работает за ручку, не перетаскивает карту вместе с формой. Поиск адресов выдаёт подсказки с координатами. Создание встречи, приглашения, план и сообщения выполняются одной транзакцией; повторная отправка с тем же ключом не создаёт дубль. Ошибка отображается, приложение не закрывает форму. |
| 6–8 | Убраны широкая пружина и прозрачное наложение текста; раскрытие карточки следует за пальцем. Горизонтальный жест возврата ограничен краем. Полная карточка с карты прокручивается. |
| 10–11 | Колода короче; свайп вниз возвращает предыдущую карточку. Вместо крупной галочки вкладка планов получает небольшой импульс. Обучение располагается в безопасной области; шаг рекомендаций имеет рабочую кнопку перехода. |
| 12–13 | Семь дат и восьмая кнопка календаря. Выбор нескольких дат фильтрует события по их объединению, без выбора всех событий за счёт подсветки сегодняшнего дня. Свайп или удержание плана открывает удаление, приглашение и переключение напоминания. Отключение учитывается и локальными, и серверными уведомлениями. |
| 14 | В планах только предстоящие события; хроника перенесена в профиль. Исправлены загрузка аватара и буква без фото. Друзья дедуплицируются. QR открывает профиль, есть сканер. «Где я был» включает линзу, «Мои места» открывает редактор адресов, уровень и значки показывают задания, условия и прогресс. Повторная отметка или принятие того же приглашения не начисляют очки заново. |
| 15 | Gemini: сохраняемые модель, темы, период и лимит; запуск, остановка, журнал и реальные статусы. Workflow принимает параметры панели. Очередь открывает описание, адрес и имеющуюся обложку; модальные окна редактирования работают на мобильной ширине. Ошибки источников и аналитики показываются. Сброс вкуса удаляет сигналы, сохраняя планы. |
| 16 | Фото сохраняют пропорции, время наложено поверх, просмотр раскрывает оригинал. Видео показывает штатное воспроизведение; кружок больше не растягивается для заполнения. Запись защищена от гонки разрешений, имеет отмену и замок. Друзья могут создать группу и отправлять события. Заголовок чата открывает вложения; свайп/удержание — закрепление, архив или скрытие диалога на устройстве. |

| 20–21 | Проверены сценарии ниже. Убраны переходы в 2ГИС и Яндекс. Навигатор работает внутри приложения: дневная карта, камера по позиции/курсу, дорожная линия и ближайшая следующая инструкция. Без дорожного ответа запуск недоступен; приближённая оценка не рисуется как настоящий маршрут. Расчёт дорог использует TomTom, автобус — существующий расчёт по OSM. |

## Подтверждённые проверки

- TypeScript приложения и worker, ESLint и Knip прошли.
- Jest: **180 тестов, 19 наборов**. Добавлены проверки формы встречи, времени Алматы, сортировки разных часовых поясов, инструкций маршрута, уровней стикеров и QR-ссылок.
- Deno: `route`, `robot-run`, `notify` прошли проверку типов. В среде JSR недоступен; для проверки использован import map на ту же установленную библиотеку Supabase из npm.
- PostgreSQL 16 + PostGIS, отдельная тестовая база: применены все миграции и новая миграция 18. SQL-регрессии проверяют повторную отправку встречи, права на точный адрес, приглашения только друзей, членство группы, карточку события в группе, однократное начисление очков и запрет чужого сброса вкуса. Тестовые изменения откатываются.
- Chromium 390×844, тестовые данные: карточка с карты и её прокрутка; адрес «Есенова 160» из тестового ответа геокодера; создание встречи; календарь; создание группы и вложения; свайп вправо, возврат вниз, раскрытие за пальцем; удержание и архив чата; предпросмотр стикера; все шаги обучения; редактирование модерации и параметры Gemini. Ошибок JavaScript в завершённых сценариях нет.
- Web-экспорт в режимах demo и live прошёл. JavaScript/Hermes-пакеты Android и iOS собраны через Expo export; это не сборка APK/IPA и не проверка нативного SDK.
- Отдельно проверен переход «Позвать → Чаты»: нижняя панель находится в пределах экрана, все вкладки доступны.
- Конфигурация Expo включает Mapbox, камеру, микрофон и схему `ryadom`. Скриншоты ниже — web, не доказательство работы аппаратных функций телефона.

## Обновление приложения

После переноса изменений в GitHub:

1. В **Actions → Supabase backend → Run workflow** выбрать ветку с этими изменениями. Требуется существующая база с миграциями 1–17 и секрет `SUPABASE_ACCESS_TOKEN`. Workflow применит миграцию 18 и обновит функции. Если секрета нет, шаги его добавления — в [KEYS.md](../../KEYS.md#автодеплой-функций-supabase-5-октября). Токены в чат не присылать.
2. Затем **Actions → Android APK → Run workflow** на той же ветке, установить полученный APK. Для iOS собрать dev build через существующий EAS-проект на устройстве.
3. Проверить на двух телефонах: GPS и поворот значка; 20 переходов между вкладками; карту внутри формы; запись с первым запросом разрешений, отменой и замком; фото разных пропорций; QR второго пользователя; отправку события в группу; приглашение с открытием точного адреса; навигатор во время движения; серверные напоминания после выключения.

Настоящий поиск Gemini и навигатор требуют серверных ключей, описанных в KEYS.md. Запуск Gemini в этой среде не выполнялся. Остановка поиска дожидается текущего запроса и не сохраняет результаты; остановка обложек прекращает новые генерации между карточками. Архив, закрепление и скрытие чатов сейчас сохраняются на этом устройстве; скрытие не удаляет сообщения у собеседника. 51 стикер — разные композиции с девятью позами маскота, а не 51 отдельная 3D-модель.
