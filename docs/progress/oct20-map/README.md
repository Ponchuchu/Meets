# Карта 3D, места и адреса, значки друзей, стикеры, медали — 20 октября (web, демо)

- `Map.png` — карта всегда в 3D, справа только компас, «+/−» и «где я». Значки друзей — «цветок» с белой каймой.
- `Friend.png` — карточка друга: вблизи дома объёмом, стикеры с белой вырубкой и цветной лентой.
- `Badges.png`, `BadgesFull.png` — формы значка на карте по рамкам (цветок, печать, мягкий квадрат, соты) и медали значков.
- `Route.png` — экран маршрута: плавающие плашки; в пути — стрелка навигатора и камера с наклоном 60°.
- Рельеф гор появится после слияния: workflow «terrain» сам зальёт тайлы в Storage.
- Места Overture и справочник адресов работают в настоящей базе (в демо их нет).
