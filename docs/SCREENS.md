# Экраны макета

Картинки: `design/png/<Имя>.png`. Исходники: `design/screens/<Имя>.dc.html`. Телефонные экраны — 390×844; если высота больше, экран прокручивается.

## Вход и регистрация

| Файл | Экран | Куда ведёт |
|---|---|---|
| `SignUp` | Старт: Google, Apple, телефон | Google/Apple → «О себе»; телефон → «Код» |
| `SignUpCode` | Код из SMS (4 цифры) | → «О себе» |
| `SignUpProfile` | 1/3 · О себе: фото, имя, дата рождения | → `Onboarding` |
| `Onboarding` | 2/3 · Что вытаскивает из дома (10 карточек, минимум 3) | → `SignUpRhythm` |
| `SignUpRhythm` | 3/3 · Когда, с кем, бюджет | → `Main` (после запроса геолокации) |

## Карта и события

| Файл | Экран | Заметки |
|---|---|---|
| `Main` | Карта (вкладка 1) | События, друзья, погода, «+», «моё место», мини-карточка события |
| `MapCalendar` | Календарь с погодой на 7 дней | Шторка на карте |
| `MapFilters` | Фильтр | Шторка на карте: цена, интересы, «на карте» |
| `EventPage` | Единый шаблон события (компонент) | Режимы `page` и `sheet` (поверх ленты) |
| `Event` | Событие: джаз во дворе | Высота 1500, прокрутка |
| `HikeEvent` | Событие: поход на Кок-Жайляу | Тот же шаблон |
| `Company` | «Ищу компанию» | Шторка поверх события |
| `CreateEvent` | Новая встреча | Кнопка «+» на карте |
| `Suggest` | Предложить событие | Из профиля |
| `MapStyles` | Три стиля карты | Бумага / Ночь / Контур |
