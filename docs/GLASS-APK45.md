# Обновление интерфейса после APK 45

База: `8265edd6d535b9340498eba2aab9bff6c54497b9`, последний опубликованный APK на момент проверки 9 ноября 2026. Релиз: https://github.com/Ponchuchu/Meets/releases/tag/apk-45 . В main этих исправлений ещё нет полностью.

Четыре раздела: карта, рекомендации, чаты, настройки с аватаркой. Профиль доступен из настроек, старый `/me` сохранён. Планы доступны календарём в рекомендациях со счётчиком приглашений; анимация сохранения направляется туда. Обучение обновлено. Светлая палитра карты и стеклянных поверхностей. Действия карточки больше не используют сердечко: календарь «Пойду», стрелка «Подробнее», «Мимо». Пропорции афиш и измеряемая высота текста из APK45 сохранены. Декоративный второй слой фото с blur отключается в экономном режиме.

Советы трёх видео переработаны в `.skills/ryadom-interface/SKILL.md`; прочитан исходный Unslop Дамира Соколовского (@heydamir, CC BY 4.0), ссылка и авторство сохранены в адаптации. Из материалов извлечены принципы: изображения по размеру, отложенная загрузка, локальные шрифты, кеш, пагинация, виртуализация, задержка поиска, компрессия на сервере, индексы по замерам, фоновые задачи и проверка на слабых телефонах. Серверные изменения без подтверждённой причины не вносились.

История других чатов недоступна инструментам текущего сеанса. Использованы git-история, FIX10 и существующие проверки. Подключённого Supabase MCP нет; публичный адрес из config найден, запрос заблокирован сетевой политикой (CONNECT 403). Добавление домена сохранено в черновик среды, требует Save/Publish в настройках. Данные production, пользовательские аккаунты и ошибки базы пока не проверены.

Направление дизайна: приложение для совместных выходов в Алматы; характер — лёгкий, тёплый, городской; материал — бумажная афиша и свет карты; цвет сосредоточен в медиа событий; календарь служит общей точкой планирования. Спокойные поверхности сохраняют контраст, декоративные эффекты не заменяют контент.
