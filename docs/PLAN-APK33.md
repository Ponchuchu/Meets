# План после APK 33 (27 октября, вечер)

По четырём видео владельца (карта, рекомендации, переход между вкладками, карточка события) и скриншотам.

## Что видно на видео
| Видео | Что происходит | Причина | Статус |
|---|---|---|---|
| Карта | деревья жёлтые и оранжевые кучами, карта тормозит | деревья ставились и на газоны дворов (`grass`), треть деревьев — осенние | ✅ только парки и кладбища, осенних 2 из 5 |
| Вкладки | «Планы» → «Карта»: 3–4 с пустой экран «Загружаю карту…» | карта удалялась при уходе с вкладки и строилась заново | ✅ карта живёт за вкладками; экраны вкладок не отцепляются |
| Рекомендации | дата и место дважды (на фото и в строках), адрес-мусор «36, Алматы · 23b769», «Встреча» у стихов и концертов | подписи на фото + строки; геокодер отдаёт обрывки адреса | ✅ подпись на фото убрана; мусор в названии места/адресе чистится; ⏳ категории — по ключевым словам |
| Карточка события | две плашки с датой, «25 ноября — 20:00 «Мне не смешно»» в описании, место дважды | плашки + строки-повторы из поста Instagram | ✅ один блок «Когда · Где · Сколько»; повторы режутся; «Театр 2act: …» → «…» |
| Постоянные места | у большинства нет фото | встроенные ссылки на Викисклад телефоны не открывают | ✅ нет нашей копии — снимок места со спутника Mapbox |

## Что ещё в работе (следующие шаги)
1. **Категории и названия карточек**: «Встреча» ставится по умолчанию — заменить на разбор по словам (концерт, стендап, спектакль, поэзия, лекция…).
2. **Дубли одного события** с разных площадок (Лорак, Меладзе): склейка по дню + месту + схожести описания, не только названия.
3. **Скорость вкладок**: экраны «Планы», «Чаты», «Профиль» собираются при первом входе — прогреть после запуска (`lazy:false` с задержкой).
4. **Лента**: после «Вернуть» карточка возвращается с той стороны, откуда ушла — проверить на телефоне наложение.
5. **Фото аквапарка и ТЦ** — свои фото (Instagram места) после продления токена и запуска сбора.
6. **Друзья**: «В сети / Не в сети» как в ВК — сделано; осталось «был(а)» по полу, когда будет в профиле.
