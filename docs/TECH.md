# Техника: стек, сервисы, данные

Решения приняты по состоянию на конец сентября 2026. Версии библиотек при установке бери актуальные. Если что-то изменилось, одна проверка в документации — и дальше, без долгих исследований.

## Карта

**Выбор — Mapbox.** Решение владельца от 28.09.2026: нужна по-настоящему хорошая карта.

**Почему Mapbox:**
- **Свой стиль.** Лучший редактор стилей (Mapbox Studio): «бумага», «ночь» и «контур» из `DESIGN.md` делаются точно, включая ступени гор на юге города (рельеф и hillshade).
- **Для живых друзей.** Плавные анимированные маркеры и свои слои.
- **Стабильность.** Надёжные серверы с SLA, в отличие от бесплатных OSM-тайлов.
- **Цена.** Бесплатно до **25 000 активных пользователей в месяц** на телефонах и до **50 000 загрузок** карты в web. Дальше $4 за 1 000 пользователей.
- **Если счёт станет большим** — переезд на MapLibre + свои тайлы. Формат стилей почти тот же, стиль переносится.

**Как подключать:**
- **iOS и Android:** `@rnmapbox/maps` с Expo config plugin (только dev build).
- **Web:** `mapbox-gl` (например через `react-map-gl`) в `Map.web.tsx` с тем же стилем.
- **Ключ:** публичный токен `EXPO_PUBLIC_MAPBOX_TOKEN` (`pk.…`); ограничить его по bundle id и доменам.
- **Без токена (демо-режим)** карта показывает статичную подложку в цветах «бумаги» с теми же пинами — чтобы всё остальное работало и проверялось.
- **Сеть облачной среды.** Если тайлы не грузятся в облачной среде при скриншотах, в её сетевых настройках нужно разрешить домены `api.mapbox.com` и `events.mapbox.com`. Попроси владельца, инструкция в `docs/KEYS.md`.

**Стили.** Три стиля в Mapbox Studio: «paper», «night», «mono» по палитрам из `DESIGN.md`.
- «Ночь» включается сама после 20:00 и в тёмной теме.
- Стиль можно сделать и кодом (style JSON в репозитории) — так он версионируется вместе с приложением.

**Пины, аватары друзей, бейджи** — свои view-аннотации (MarkerView) или символьные слои по макету `Main`. Много точек — кластеризация.

**Кнопка «Маршрут»** в событии не строит маршрут у нас. Она открывает шторку выбора приложения, которым в Алматы реально пользуются: **2ГИС**, **Яндекс Карты**, **Google Maps**, Apple Карты на iOS. Если приложения нет — веб-ссылка. Это бесплатно и без ключей.

**Почему не другие:**
- **2ГИС** — лучшие данные по Алматы (адреса, входы, ТРЦ). Но официального SDK для React Native нет, есть только неподдерживаемые сторонние обёртки. Лицензия через отдел продаж, хранить результаты геокодера без договора нельзя. Используем как приложение для «Маршрута».
- **Яндекс MapKit** — бесплатные условия запрещают показывать перемещение людей в реальном времени, а это наши друзья на карте.
- **Google Maps** — на телефонах бесплатно без лимита, но стиль настраивается слабее (нет наших ступеней гор и тонкой типографики подписей), а web платный после 10 000 загрузок. Запасной вариант, если Mapbox по какой-то причине не подойдёт.
- **MapLibre + OpenFreeMap** — бесплатно и тот же формат стилей, но без гарантий доступности. План Б на случай роста счёта.

## Геокодинг и площадки

- **Своя таблица `venues`** с алиасами. ИИ сопоставляет пост с площадкой, этаж хранится отдельным полем.
- **Для новых адресов** — только подсказка точки, модератор подтверждает:
  - **Nominatim:** не больше 1 запроса/с, кэшировать, атрибуция ODbL;
  - либо **Geoapify:** 3 000 запросов/день, коммерция с атрибуцией.
- **Не хранить результаты** 2GIS, Яндекса и Google: их условия запрещают хранение без договора или требуют показ на их картах.

## Вход

- **Supabase Auth.**
- **Телефон (OTP 4 цифры).** Supabase Send SMS Hook → Edge Function → казахстанский SMS-шлюз **Mobizon.kz** или **SMSC.kz**.
  - Цена: ~11–20 ₸ за SMS + абонплата за имя отправителя; шаблоны OTP нужно зарегистрировать у операторов.
  - Дешевле: **Telegram Gateway** ($0.01 за код) с запасным SMS.
  - Twilio работает из коробки, но ~$0.34 за SMS в Казахстан.
  - Включить капчу и лимиты против SMS-накрутки.
- **Google:** `@react-native-google-signin/google-signin` → `supabase.auth.signInWithIdToken` (нужен dev build).
- **Apple:** `expo-apple-authentication`. **Обязателен на iOS**, раз есть вход через Google (App Store 4.8). Имя приходит только при первом входе — сохранить сразу.
- **Демо-режим:** любой номер, код 4821. Google и Apple сразу пускают как «Данил».

## Погода

- **Open-Meteo** через Edge Function с кэшем в таблице (обновление по pg_cron раз в час). Клиент в API напрямую не ходит.
- Бесплатно **только для некоммерческого** использования. Перед монетизацией — платный тариф Open-Meteo.
- **Данные:** текущая погода, по часам, на 7 дней для календаря.
- **Демо:** статичный прогноз.

## ИИ для пайплайна

- **Anthropic API:**
  - `claude-haiku-4-5-20251001` — классификация и извлечение: structured outputs, vision для афиш;
  - `claude-sonnet-5` — повтор при низкой уверенности.
- **Стоимость** ~$3.5–5 на 1 000 постов на Haiku. Batch API дешевле вдвое, но асинхронный.
- **Ключ** только на сервере (воркер, Edge Functions), никогда в приложении.

## Источники событий

Как есть на сентябрь 2026:

- **Яндекс Афиша, Ticketon, Kino.kz, Sxodim:** публичного API на чтение нет. Парсинг HTML хрупкий и нарушает условия сайтов, лучше договариваться о партнёрстве.
- **Telegram:** бот не читает чужие каналы. Варианты:
  - публичное веб-превью `t.me/s/<канал>`;
  - MTProto-клиент с пользовательским аккаунтом. Риск бана; условия Telegram API ограничивают использование данных для ИИ.
- **Threads:** поиск по ключевым словам требует разрешения `threads_keyword_search` и App Review у Meta.
- **План на MVP:**
  1. события вручную из админки;
  2. «Предложить событие» от пользователей;
  3. публичные превью нескольких Telegram-каналов.

  Остальное — после юридической проверки. Храним краткую выжимку и ссылку на источник, а не полный текст и картинки. Предусмотреть удаление по запросу.

## Реальное время

- **Чаты:** таблица `messages` + Realtime (Postgres Changes или Broadcast) по участникам чата.
- **Геолокация друзей:**
  - Realtime **Broadcast** по приватным каналам с RLS;
  - отправлять только при сдвиге больше 30–50 м и только тем, у кого сейчас открыта карта;
  - на сервере храним только последнюю точку (`locations_last`), истории нет;
  - скорость — `coords.speed` (м/с → км/ч), показываем при > 3 км/ч.
- **Геолокация в MVP — только «при использовании приложения».**
  - «Делиться 2 часа» — пока приложение открыто, плюс последняя точка.
  - Фоновая геолокация — позже, отдельной опцией: высокий риск отказа в Google Play для сценария «друзья рядом».
- **Соты «открытого города»:** `h3-js`, разрешение 8 (≈0.74 км², ребро ≈ 460 м). Хранить строкой, расширения h3 в Supabase нет.

## Медиа в чате

- **Фото и видео:** `expo-image-picker`, загрузка в Supabase Storage (приватный бакет, подписанные ссылки).
- **Голосовые:** `expo-audio` (m4a / AAC), волна по уровню сигнала. `expo-av` удалён в SDK 55 — не использовать.
- **Кружки:** `expo-camera` `CameraView.recordAsync` (480p, до 60 с, фронтальная камера, зеркало), круглая маска в интерфейсе. Воспроизведение — `expo-video`.
- **Нельзя:** ffmpeg на клиенте (FFmpegKit закрыт).
- **От незнакомых** фото и видео приходят размытыми до нажатия «показать».

## Пуши

- `expo-notifications` + **Expo Push Service** (бесплатно). Нужны FCM v1 (Android) и APNs-ключ (iOS).
- Правила частоты и тихие часы — `PRODUCT.md`, раздел 15. Считать на сервере.

## Модель данных (стартовая)

Все таблицы с **RLS**. Миграции в `supabase/migrations/`.

- **Люди и настройки:**
  - `profiles` — имя, дата рождения, фото, @ник, о себе, instagram, флаги приватности;
  - `start_answers` — интересы, время, с кем, бюджет;
  - `friendships`, `friend_requests`, `blocks`, `reports`;
  - `marker_settings` — режим скорости, статус, цвет кольца, фото/буква, невидимка, `share_until`, `home_geog` (зона дома 300 м, никому не видна);
  - `locations_last` — `user_id`, `geog`, `speed`, `heading`, `updated_at`.
- **События:**
  - `venues` — название, алиасы, `geog`, адрес;
  - `events` — название, категория, теги, начало/конец, `is_long`, `venue_id`, адрес, заметка к адресу, цены, `is_free`, описание, организатор, обложка, источник, статус, `visibility`, `created_by`;
  - `attendance` — `user_id`, `event_id`, статус (`going` / `saved` / `skipped` / `arrived` / `cancelled`), время;
  - `company_requests` — зачем идёт (до 2), кто видит, пара слов;
  - `invites` — кто, кого, куда (событие или «своё место»), ответ;
  - `meetups` — «Создать встречу» (или `events` с `visibility='friends'`) + `meetup_items` («кто что принесёт»).
- **Чаты:**
  - `chats` — `direct` / `event`, `closes_at`;
  - `chat_members`;
  - `messages` — тип: `text` / `photo` / `video` / `voice` / `circle` / `sticker` / `invite` / `poll` / `system`;
  - `polls`, `poll_votes`.
- **Рекомендации:** `taste`, `signals` (см. `RECOMMENDATIONS.md`).
- **Достижения:** `visited_cells` (`user_id`, `h3`, `city`, `first_at`), `badges`, `user_badges`, `cities_visited`.
- **Пайплайн:** `sources`, `raw_posts`, `event_drafts` (очередь модерации), роли команды (`staff`).
- **Уведомления:** `push_tokens`, `notification_prefs`.

## Правовые и магазинные требования

- **Локализация данных РК.** По закону о персональных данных (№ 94-V) базы с персональными данными граждан РК должны находиться в Казахстане. У Supabase нет региона в РК. **Для MVP и теста это не блокер**, но перед публичным запуском нужен юрист. Возможный вариант — self-hosted Supabase в казахстанском облаке.
- **App Store:**
  - удаление аккаунта внутри приложения;
  - для чатов и UGC — жалобы, блокировка, фильтр контента;
  - политика конфиденциальности;
  - 18+;
  - Sign in with Apple.
- **Google Play:**
  - личный аккаунт разработчика, созданный после ноября 2023, перед продакшеном проходит закрытый тест (12 тестеров, 14 дней);
  - декларации геолокации.
- **Аккаунты:** Apple Developer $99/год, Google Play $25 один раз.
