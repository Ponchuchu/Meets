# Выпуск в App Store и Google Play

Что уже сделано в приложении и что заполнить в консолях магазинов. Ключи и аккаунты — `KEYS.md`.

## Сборки (EAS)

Профили — `eas.json`:

| Профиль | Для чего | Команда |
|---|---|---|
| `development` | dev build для своего телефона: карта, пуши, вход через Apple работают (в Expo Go — нет) | `npx eas build -p android --profile development` (или `-p ios`) |
| `preview` | тестерам: APK для Android, internal-сборка для iOS | `npx eas build -p all --profile preview` |
| `production` | в магазины, номер сборки растёт сам | `npx eas build -p all --profile production`, затем `npx eas submit -p all` |

Первый раз: `npx eas login`, `npx eas init` (впишет `projectId` в `app.json` — от него зависят пуши), `npx eas credentials` (ключи подписи создаст EAS).

Идентификаторы: iOS `kz.ryadom.app`, Android `kz.ryadom.app`.

## Требования магазинов — где это в приложении

| Требование | Где |
|---|---|
| Удаление аккаунта внутри приложения (App Store 5.1.1) | «Профиль» → «Настройки» → «Удалить аккаунт». Сервер: `delete_my_account()` стирает профиль, сообщения, файлы, планы, друзей, точки, вкус |
| Жалоба и блок, фильтр контента (UGC, App Store 1.2) | Профиль человека и чат: «Пожаловаться», «Заблокировать» — в одно нажатие. Медиа от незнакомых размыты до «показать». Жалобы — таблица `reports`, разбирает команда |
| Политика конфиденциальности | В приложении: «Настройки» → «Политика конфиденциальности» (`/legal?doc=privacy`). Этот же адрес web-версии указать в App Store Connect и Google Play |
| Правила сообщества | «Настройки» → «Правила сообщества» (`/legal?doc=rules`) |
| 18+ | Регистрация не пускает младше 18 (`src/auth/rules.ts`), в базе — проверка даты рождения. В анкете магазинов: возрастной рейтинг 17+ (App Store) / 18+ (Google Play), есть общение между людьми и геолокация |
| Sign in with Apple (App Store 4.8) | Кнопка «Продолжить с Apple» на iPhone — настоящий вход (`expo-apple-authentication` → Supabase) |
| Геолокация только когда приложение открыто | `app.json`: тексты разрешений, фоновая геолокация запрещена (`ACCESS_BACKGROUND_LOCATION` в blockedPermissions) |

## Google Play: декларации

- **Геолокация:** только «в процессе использования». Зачем: показать события рядом и точку друзьям, если человек сам включил «делиться». В фоне не собирается, фоновой декларации нет.
- **Data safety** (что собираем → зачем → передаём ли):
  - телефон, имя, фото, дата рождения — аккаунт, функциональность; не передаём;
  - примерное и точное местоположение — функциональность (друзья, события рядом); не передаём, истории не храним;
  - сообщения, фото и видео в чатах — функциональность; не передаём;
  - действия в приложении («пойду», «мимо») — персонализация и аналитика; не передаём;
  - идентификатор устройства для пушей — функциональность.
  Данные шифруются при передаче (HTTPS), человек может удалить аккаунт в приложении.
- **Закрытый тест:** для личного аккаунта разработчика, созданного после ноября 2023, — 12 тестеров 14 дней до продакшена. Для этого подходит профиль `preview` → «Закрытое тестирование».

## App Store: App Privacy

Те же пункты, что в Data safety: Contact Info (телефон), User Content (сообщения, фото), Location (Precise, App Functionality, не для трекинга), Identifiers (push token), Usage Data (App Functionality, Analytics). **Tracking: No.**

## До публичного запуска

- Юрист: локализация персональных данных граждан РК (`TECH.md`, «Правовые и магазинные требования») и текст политики.
- Mapbox: ограничить публичный токен по bundle id и адресу сайта (`KEYS.md`).
- Open-Meteo: платный тариф, если появится монетизация.
- **Подписи карты — включить перед Google Play** (Данил скажет, когда; для тестов скрыты): сборка с `EXPO_PUBLIC_MAP_ATTRIBUTION=true`
  (логотип и «i» Mapbox), плюс строка «© Mapbox © OpenStreetMap contributors · Overture Maps Foundation · Copernicus DEM» на карте
  и в «Настройки → О приложении». Тексты подписей — `docs/MAP-DATA.md`.

## Производительность

Проверка — `npm run build:web && npm run perf`: web-версия в Chromium, процессор замедлен в 6 раз (≈ слабый Android), экран 390×844. Результат — `docs/progress/stage-10/perf.json`.

| Экран | Контент на экране | Кадры при перетаскивании | Самый долгий кадр |
|---|---|---|---|
| Карта | 2,8 с | 62 к/с | 17 мс |
| «Для тебя» | 3,4 с | 58 к/с | 67 мс |

Что сделано по итогам замеров:
- mapbox-gl (~1 МБ) грузится отдельным куском после первого экрана: карта на слабом процессоре появлялась за 4,4 с, теперь за 2,8 с;
- верхняя карточка «Для тебя» — отдельный слой (`will-change: transform`): при перетаскивании было 10 к/с и кадры по 333 мс, стало 58 к/с.

На телефоне (dev build) карта рисуется нативным Mapbox, а анимации Reanimated идут в UI-потоке — там запас ещё больше. Перед релизом стоит пройти то же самое руками на недорогом Android (например, Galaxy A0x): открыть карту, полистать «Для тебя», открыть чат с фото.
