# План сборки

Бери первый этап без галочки. Когда этап готов:
1. отметь галочки;
2. допиши строку «Итог:»: что сделано и где скриншоты;
3. запушь.

Каждый этап заканчивается работающим приложением в демо-режиме: без ключей, на данных из макета.

**Готово, когда** (для каждого этапа):
- экраны этапа совпадают с `design/png` на 390×844;
- тексты дословно из макета;
- `tsc`, линтер и тесты зелёные;
- скриншоты лежат в `docs/progress/<этап>/`.

## Этап 11 — правки владельца после первого просмотра

Карта
- [ ] Логотип Mapbox не виден (атрибуция остаётся в «i» по лицензии)
- [ ] Карточку события и друга можно смахнуть вниз или закрыть крестиком — остаётся чистая карта
- [ ] Несколько событий в одной точке (кинотеатр в ТРЦ) — тап открывает список с датами и событиями
- [ ] Физика масштаба: вдали — маленькие иконки без подписей, ближе — крупнее и с подписями; цвет иконки по категории; тап по точке приближает к ней
- [ ] Погода на карте: лёгкий дождь, снег или листья по прогнозу

Календарь и фильтры
- [ ] В календаре — только календарь (карточка снизу скрыта), маленькая кнопка «Сбросить»
- [ ] Под датой — иконка погоды
- [ ] Баг: при включённом фильтре тап по другу открывал профиль и стикеры не того вида
- [ ] Бюджет до нуля — включается «Только бесплатные»; лишние подписи под переключателями убраны

Друг на карте
- [ ] Без «Профиль», «на месте», синей плашки «Показываю …», строки «вечером идёт на джаз»; имя или аватар — в профиль; только «обновлено N мин назад» и скорость
