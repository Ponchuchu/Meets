# План сборки

Бери первый этап без галочки. Когда этап готов:
1. отметь галочки;
2. допиши строку «Итог:»: что сделано и где скриншоты;
3. запушь.

Каждый этап заканчивается работающим приложением в демо-режиме: без ключей, на данных из макета.

**Готово, когда** (для каждого этапа):
- экраны этапа совпадают с `design/png` на 390×844;
- тексты дословно из макета;
- `tsc`, линтер и тесты зелёные;
- скриншоты лежат в `docs/progress/<этап>/`.
