## 0. Подход к коду

**Интерфейс переписываем под v6 полностью, рабочие модули — переиспользуем.** Переписать всё с нуля дороже и рискованнее: рабочий слой данных, рекомендации и робот уже проверены тестами.

| Оставить и доработать | Переписать под v6 | Удалить |
|---|---|---|
| `src/data/supabase.ts`, `client.ts`, `realtime.ts`, `sync.ts` | Все экраны в `app/` (вкладки, карта, карточка, чаты, профиль, вход) | Старые экраны v2–v4 и их компоненты |
| `src/reco/*` (лента), `src/map/lifecycle.ts`, `filters.ts`, `style.ts` | `src/components/TabBar.tsx` → панель `V6TabBar` | Вкладку «Люди» |
| `src/transit/bus.ts`, `worker/*`, `supabase/functions/*` | Верх карты, фильтры, слои, шторки | Чипс «Сегодня ▾» и ленту дат |
| Тесты в `src/__tests__` и `worker/__tests__` | | Демо-данные из основного пути (см. ниже) |

**Без демо:**
- Сборка альфы: `EXPO_PUBLIC_DATA_MODE=live`. В этом режиме слой данных никогда не подставляет демо-друзей, демо-чаты и демо-события.
- Нет сети — кэш последних данных, строка «Нет интернета», отправки в очереди.
- Сервер недоступен — «Нет связи с сервером · Повторить», а не фальшивые данные.
- Демо-реализация `src/data/demo.ts` остаётся только для тестов и web-скриншотов (`EXPO_PUBLIC_DATA_MODE=demo`).

**Правила качества** — как в `CLAUDE.md`, плюс «Без глюков» из `V4.md`. Перед каждым коммитом: `npm run typecheck`, `npm run lint`, `npm test`.

## 1. Тестеры и вход без SMS

SMS-шлюза пока нет. Для альфы — вход по коду для списка тестеров, без SMS:

- Номера и коды тестеров владелец передаёт **в сообщении**, не в репозиторий. Хранить в секрете Supabase **`ALPHA_TESTERS`** в формате `+77470000000:0000,+77770000000:0000`. Номера в код, миграции, тесты и документы **не писать**.
- Edge Function **`alpha-login`**:
  1. принимает `{ phone, code }`;
  2. сверяет пару с `ALPHA_TESTERS`;
  3. если пользователя нет — создаёт его через admin API (`phone`, `phone_confirm: true`) с паролем `HMAC(ALPHA_SECRET, phone)`;
  4. входит этим паролем (`signInWithPassword({ phone, password })`) и возвращает сессию;
  5. приложение делает `supabase.auth.setSession(...)`.

  Неверный код — 401, не больше 5 попыток за 10 минут на номер.
- Экран кода — `V5LoginCode`: 4 клетки (длина кода берётся из ответа функции `alpha-login?probe`), автопереход, неверный — клетки трясутся. Повтор кода не нужен: «Код дал разработчик».
- Номер не из списка — «Пока вход только для тестеров. Напиши Данилу» (без SMS).
- Позже настоящий вход идёт по `TECH.md` (Send SMS Hook + Mobizon), функция `alpha-login` выключается флагом `app_flags.alpha_login`.

**Данные тестеров** — миграция-сид без номеров, по `auth.users.phone` из `ALPHA_TESTERS` при первом входе (в функции `alpha-login`):
- Данил — в `staff` (панель разработчика), имя «Данил», ник `danil`;
- второй тестер — обычный пользователь, имя «Ердос», ник `erdos`;
- тестеры автоматически друзья между собой (`friendships`), видят друг друга на карте.

### А8 — проверка на двух телефонах

Сценарий приёмки. Пройти вдвоём, записать короткое видео, кадры — в `docs/progress/alpha/`:

1. Данил и Ердос ставят APK, входят по своим номерам и кодам. Видят заставку, обучение, карту со своей точкой.
2. Данил в панели разработчика жмёт «Искать сейчас», через 1–2 минуты одобряет 3 карточки. Они появляются на карте и в Рекомендациях у Ердоса.
3. Ердос свайпает событие вправо: оно улетает в «Планы». Нажимает «Позвать» Данила. У Данила приходит пуш, в «Планах» — «Зовут», в чате — карточка. Данил отвечает ✓.
4. Оба гуляют или едут: каждый видит другого на карте со скоростью и хвостом. Ердос закрывает приложение — у Данила «2 мин», через 2–3 минуты точка обновляется.
5. Ердос включает невидимку на 1 час — у Данила точка замерла.
6. Голосовое с замком и кружок туда и обратно. Ответ на сообщение из пуша.
7. Карточка → адрес → «Маршрут здесь»: время на машине с пробками, пешком, автобус (если есть).
8. Бамп: стукнуться телефонами → «Бамп засчитан» (они уже друзья — проверить с третьим телефоном или удалить дружбу и стукнуться снова).
9. Выключить интернет — строка «Нет интернета», данные из кэша, сообщение уходит после включения.
