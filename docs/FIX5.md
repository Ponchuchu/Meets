# FIX5 — проверка APK 25 октября (список Данила)

Основа — `main` после PR #24. Работа — в `claude/apk-bugs-design-overhaul-vfs7zl`. Где расходится с FIX4 и старше — прав FIX5.
Скриншоты (web, демо-данные): [progress/fix5](progress/fix5/).

## Что нашли

- **Группа не появлялась, чат с Ердосом открывался «чужим»**: в базе всё было (личный чат на 82 сообщения и группа «Ивентики»). Группа без сообщений приходила с сервера с пустым «последним сообщением», разбор его времени падал — и пропадал **весь** список чатов. Отсюда «Чат · не в друзьях» и запрет писать.
- **Пустая карта при входе**: перелёт камеры после заставки заказывался, пока карта ещё грузилась; Android его терял, а запрет «камеру уже двигали» не давал вернуть стартовую точку.
- **Вылеты**: в журнале ошибок — «Maximum update depth exceeded». Точный источник по журналу не виден; убраны известные тяжёлые места: при многих планах пересобирались все напоминания разом (Android держит ограниченное число будильников), список планов рисовался целиком.
- **Подтормаживания**: кэш на телефоне каждые 5 с превращался в JSON целиком (события, переписки) — даже когда менялись только точки друзей.
- **Фото Терренкура и Кок-Тобе**: ссылки Викисклада шли через переадресацию и без подписи приложения — Wikimedia такие отклоняет.

## Сделано

| Что | Как |
|---|---|
| Лента | Порядок ближайших карточек «замораживается» — следующая карточка не подменяется той, что была через четыре. «Пойду» на событии с сеансами или долгом событии — шторка поверх ленты: лента дней плашками, чипы времени и барабан; смахнул шторку — карточку можно листать дальше |
| Выбор дня | Вместо колонки дат — лента дней «сб · 25 · окт», «сегодня/завтра», выходные цветом, кнопка «месяц» с календарём; быстрые «Утром / Днём / Вечером»; итог на кнопке «Суббота, 25 октября · 19:00» |
| Подсказка жестов | Только после 45 с бездействия, первый раз, через 5 дней, через месяц — и больше никогда |
| Открытая карточка | Фото в тех же пропорциях, что на карточке ленты, — не растягивается |
| Фото мест | Прямые ссылки upload.wikimedia.org (960 px) и подпись приложения; не открылось первое — берётся следующее |
| Карта | Не пустая при входе; при возврате на вкладку — там, где оставил; после фона перерисовывается сама. Деревья — в глубине парков, а не по кромке (кромка совпадала со стенами домов) |
| Значки событий | Объёмные «пуговицы» с бортиком, бликом и тенью; издалека обычные события — маленькие точки, карта не рябит |
| Мои места | На карте — булавки-капли своего цвета; страница: карта со всеми местами, плитки «Дом / Работа / Учёба / Зал / Дача», избранное отдельно |
| Заряд друга | Батарейка с процентом у аватарки на карте и в карточке друга: заряжается — зелёная с молнией, мало — красная (миграция 40) |
| Чаты | Список не падает от пустой группы; ошибка загрузки видна; новый вид сообщений — светлые пузыри без рамок, мягкие тени, скругления |
| Планы | «Дальше по плану» с фото и обратным отсчётом, лента дней с точками, «Зовут» с «Не смогу / Иду», расписание по дням на линии времени, порции по 30; напоминаний — 40 ближайших |
| Шаги | Рейтинг друзей за любой день (по умолчанию сегодня) или неделю, прошлые недели стрелками, пьедестал топ-3 с аватарками и короной; свои столбики нажимаются — шаги за день и сумма за неделю (миграция 41) |
| Стикеры | Набор «Мемы» (я умер, клоун, сотка, огонь, персик, легенда…) и мемные картинки у всех подписей вместо оранжевых персонажей. На карте: перчатки бьют три раза с «БАМ!» и отдачей, сердце бьётся «тук-тук» с вибрацией в такт и новым звуком, баклажан пружинит, салют разлетается |
| Скорость | Кэш пишется только при настоящих изменениях; стикер на карте показывается сразу, отправка фоном; значки событий не перерисовываются при каждом шаге зума; запросы «кто идёт» порциями |
