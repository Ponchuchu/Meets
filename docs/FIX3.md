# FIX3 — проверка APK 20 октября (`apk-review-20261020-quality-frames`, `09c277d`)

Основа — ветка `codex/oct20-quality-and-frames` (последняя APK). Работа идёт в `claude/app-bugs-optimization-dyvpj1`.
Где этот документ расходится с `V6.md` и другими, прав FIX3 (это самые свежие решения владельца).

## Что нашли при разборе

- **В настоящей базе нет миграций 27 (12 окт.), 24 и 29 (20 окт.).** Обновление сервера их не применяло: в списке шагов процесса GitHub Actions их не было.
  Поэтому не грузятся список чатов (`my_chat_summaries`), отправка сообщений (`send_chat_message`), шаги, выбор даты посещения, рамки и заявки в друзья.
  Друг и 26 сообщений в базе есть — приложение их просто не может получить.
- **«Сводка не загрузилась» в аналитике** — ошибка в SQL `admin_overview` («found» совпадает со служебным словом PL/pgSQL). Не связь и не миграция.
- **Пуши:** в `push_tokens` нет ни одного токена — телефон не регистрируется. Для Android нужен ключ FCM в EAS (см. `KEYS.md`).
- **Вылет при маршруте:** журнала падения с телефона нет; добавлен сбор ошибок (`client_errors`) и защита от всех найденных опасных мест.

## Правила

- Ничего не ломать: перед коммитом `tsc`, eslint, jest, SQL-тесты.
- Тексты по-русски, на «ты», без эмодзи, кнопки ≥ 44 pt.
- Приватность: воспоминания и ночёвки по умолчанию видишь только ты; друзьям — если разрешил в «Приватности». Точные адреса ночёвок не показываются никому.
- Механика рекомендаций и расписаний мест не показывается пользователю.

## Что осталось и почему

- **3D-здания (Ф13).** Карта берёт здания из Mapbox Streets; гостиницы «Казахстан» и части высоток в их данных нет или нет высоты. Варианты: стиль Mapbox Standard (свои 3D-ориентиры, но тяжелее для Poco M6) или здания Overture со своими тайлами. Нужно решение владельца и замер на телефоне.
- **Пуши на Android** работают только после ключа Firebase: `docs/KEYS.md`, раздел «Пуши на Android (FIX3)».
- **Вылет маршрута** закрыт по всем найденным причинам, но проверить можно только на телефоне. Если повторится — «Панель → Аналитика → Ошибки в приложении» покажет экран и текст ошибки.
