# FIX10 — проверка APK35/36, медиа и социальные сценарии

База — официальный APK36, `56c79b9`, PR31 уже слит в main (`c49eb77`). Первоначальные Perfetto, HWUI framestats, PSS и logcat сняты до изменений. Эмуляторы Android15 используют SwiftShader и ARM translation: эти значения не являются FPS физического телефона. HWUI не покрывает отдельные поверхности Mapbox/видео. В35 галереи и видео ещё не работали, поэтому их нагрузка отличается от36.

## Исправления

- Переходная шапка события использует ту же композицию обложки и фактов, что полная страница. Старые blur/date chips не появляются при раскрытии. Звук расположен ниже Share; заголовок оставляет место счётчику галереи.
- Общие шторки и dimmer получили Android elevation выше свайп-карточек. В36 карточка рекомендаций фактически рисовалась поверх шторки места.
- Одиночное медиа не создаёт FlatList. Галерея ограничивает текущую страницу после обновления. Native player останавливается при blur/background, включая замороженную вкладку; состояние ошибки привязано к источнику.
- Новый личный чат ждёт серверный UUID до появления редактора сообщения; ошибка показывает повтор. Поздний ответ после ухода не меняет экран.
- Выбор собственной даты ждёт подтверждения сервера, показывает ошибку и защищён от двойного нажатия.
- Поиск друзей прокручивается, показывает ожидание и повтор после ошибки. Live Bump больше не выдаёт произвольного человека за найденного рядом; сервис честно обозначен недоступным.
- Серверные pending-заявки не скрываются устаревшим локальным флагом. Удаление друга очищает флаги только этого человека, позволяя добавить его снова. Заголовок заявки и профиль человека вне кеша получают собственные публичные данные.
- Inbox/presence работают из корня приложения, включая прямые ссылки вне вкладок.
- Запрос доступа к шагам вызывается кнопкой профиля, а не неожиданно во время входа в чаты/карту. Уже выданные разрешения продолжают использоваться.
- Профиль без видимого lastSeen больше не повторяет два чипса «не в друзьях». Подложка уведомлений поиска точки отделена от Text: после запуска Expo dev environment общий ViewStyle больше не ломает проверку TextStyle.

## Фактически проверено

Два отдельных Android, аккаунты Danil и Denis QA: заявка и принятие дружбы, создание личного чата, текст и стикеры в обе стороны, фото из системной галереи и полноэкранное открытие у получателя. Сообщение без сети: ноль серверных записей до восстановления, одна после, доставка получателю. Создана QA-группа, получен ответ второго участника. Создана приватная QA-встреча, приглашение получено в чате; принятие и отмена участия переключают состояние карточки. Реальные контакты для отправки тестовых сообщений не использовались.

68 наборов / 484 автотеста прошли. TypeScript приложения/worker, ESLint и SQL review check проверяются отдельно в отчёте запуска. Knip на Windows заблокирован политикой Application Control для нативного oxc-parser. Локальный release дошёл до JS bundle, затем Device Guard заблокировал hermesc.exe; защита не менялась. Debug APK и облачная release-сборка требуют отдельной нативной проверки. Непроверенное не считается исправленным на устройстве.

Полные локальные трассы, снимки, воспроизведения и план восстановления сохранены в отчёте QA рабочего чата. Сессии, ключи, APK и резервные копии в Git не включаются. Изменений схемы, RLS или production Auth settings нет; создан только явно разрешённый тестовый аккаунт.

## Отчёты QA и что осталось проверить

Полные отчёты рабочего чата сохранены в [`docs/qa-apk36/`](qa-apk36/): `restoration-plan.md` (реестр находок и ход проверки), `performance-findings.md` (Perfetto, framestats, PSS APK35/36), `design-audit.md`, `test-audit.md`. Трассы, снимки и резервные копии сессий в Git не входят.

Не подтверждено на устройстве (ждёт нового APK):

- правки шапки события, порядка слоёв шторок и остановки видео при уходе с экрана;
- разделение кнопок Share и звука и контраст счётчика галереи — правка сделана на ПК, в PR её нет;
- уход дублирующегося чипса «не в друзьях» в профиле;
- перезапуск приложения после действий, повторная дружба в исходном направлении, выбор нескольких дат;
- повторные трассы производительности: замеры эмулятора (SwiftShader, ARM-трансляция) не равны FPS телефона, debug нельзя сравнивать с release.

Knip локально на Windows не запускался (Application Control блокирует oxc-parser) — его проходит CI. Release-сборка локально невозможна (Device Guard блокирует hermesc.exe), нужна облачная «Android APK».
