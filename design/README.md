# Макет «рядом.»

Макет сделан на холсте Claude Design. Здесь лежит его выгрузка.

- `png/` — снимок каждого экрана в исходном состоянии. Телефонные экраны 390×844, длинные экраны прокручиваются (высота больше 844). **Смотри сюда в первую очередь.**
- `screens/` — исходники. Каждый файл — один экран или схема.
- `canvas.json` — список экранов, их заголовки и размеры (`boards`), порядок (`order`), подписи рядов (`notes`).
- `assets/` — фото для демо-данных. В исходниках на них уже ведут пути `../assets/<имя>.jpg`.

## Как читать `.dc.html`

Это HTML с инлайн-стилями и маленьким шаблонизатором. Отдельно в браузере он не откроется: нужен рантайм холста. Поэтому используй его как точную спецификацию, а не как код для копирования.

- Разметка внутри `<x-dc>`: все размеры, цвета и тексты указаны прямо в `style="…"`.
- `{{a.b}}` — значение из `renderVals()` в `<script type="text/x-dc">` внизу файла. Там же:
  - состояние экрана (`this.state`);
  - данные: списки событий, друзей, сообщений;
  - логика: таймеры, свайпы, переходы.
- `<sc-for list="{{items}}" as="x">` — цикл, `<sc-if value="{{flag}}">` — условие.
- `<dc-import name="X" prop="…">` — вставка другого экрана-компонента с параметрами.
- `data-props` в теге `<script>` — переключаемые варианты экрана (например `active` у таб-бара).
- `<a href="Feed.dc.html">` — переход на другой экран.

## Экраны-обёртки

Эти файлы показывают другой экран в нужном состоянии. Настоящая разметка — в файле справа.

| Файл | Что показывает |
|---|---|
| `Event`, `HikeEvent` | `EventPage` с `ev="jazz"` / `ev="hike"` |
| `MapCalendar`, `MapFilters` | `Main` с открытой шторкой календаря / фильтров |
| `MapFocus`, `MapMoving`, `MapInvite` | `Main` с фокусом на друге (Игорь стоит, Денис едет), шторка «Позвать куда-то» |
| `ChatAttach`, `ChatSheets` | `DirectChat` с панелью вложений / шторкой по тапу на аватарку |
| `MeBadges` | `Me` с открытой шторкой всех значков |
| `SignUpCode`, `SignUpProfile`, `SignUpRhythm` | `SignUp` на шагах «код», «о себе», «ритм» |

Компоненты, которые переиспользуются везде:
- `TabBar` — таб-бар;
- `MapBase` — подложка карты с палитрами paper/night/mono;
- `EventPage` — единый шаблон события.
